## 交付前四处理论一致性核对（已在本版对齐）

| # | 议题 | 本版口径 |
|---|---|---|
| C1 | 全模型源是否提供 | **已提供**：14 个 `.mgbx` + 对应 `.XOUT` 随作品 ZIP 提交。但其 MIDAS 原生解本身奇异（最大一份含 265 条位移 `ABNORMAL` + 234 个自由度 `MAY BE SINGULAR`），且无任何 `.XOUT` 出现 32.22，故 32.22mm 取源计算书表格3 |
| C2 | 材质卡点归因 | **我方材质载荷问题，不是"云侧不认自定义材质"**：15 步写入全 200/201，唯一失败点是 `/doc/ANAL` 回 `[错误] 材料 没有定义。`。候选变量待对照实验分辨——① `ELAST=6e9` 在本单位制（`FORCE:KN / DIST:M`，即 kPa）下等于 6000 GPa，超范围；② 材质名含括号/逗号，而同实例历史成功并可读回的自定义 USER 材质名为 `Q355`、`ELAST=206000000`（=206 GPa） |
| C3 | 全链路耗时口径 | **快照态不计全链路成绩**。快照态约 0.03s 只说明"一条命令跑完"，真值态耗时以 `midas_used=true` 的运行计 |
| C4 | 计时口径漏真实耗时 | 已如实记录：`analyze_s=0.0 / t_wall_s=0.05`，而 trace 里 `analyze 200 (9.0s)` → 判据 3b 的 `wall ≤ 600s` 仅在 `midas_used=true` 时成立 |

## 现场可做的材质对照实验（30 秒，做完成即可翻实时态）

```powershell
$K="<活 key>"; $B="https://moa-engineers.midasit.cn:443/gen"
curl.exe -s -X PUT -H "MAPI-Key: $K" -H "Content-Type: application/json" `
 -d '{"Assign":{"1":{"TYPE":"USER","NAME":"BAMBOO_6GPA","bMASS_DENS":true,"DAMP_RAT":0.05,"PARAM":[{"P_TYPE":2,"ELAST":6000000,"POISN":0.3,"THERMAL":0.00001,"DEN":7.0,"MASS":0.71}]}}}' `
 "$B/db/MATL"
curl.exe -s -H "MAPI-Key: $K" "$B/db/MATL"   # 读回含 "ELAST":6000000 → 卡点确认为单位
```
发两次 PUT 做对照：一次只改单位（`ELAST=6000000`，名字保持带括号），一次只改名字（`NAME=BAMBOO`，`ELAST` 保持 6e9），各自看 ANAL 是否不再报"材料没有定义"。
